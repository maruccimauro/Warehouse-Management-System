# Visualizar unidad de medida (ZW83)

La transacción `ZW83` muestra los datos de una unidad de medida sin modificarlos. Cualquier usuario con sesión la puede abrir y está en el menú en **Logística ▸ Catálogo**.

## Pantalla inicial {#inicial}

Ingrese la **Unidad** y presione <kbd>F8</kbd>.

### Unidad {#unit}

Código de la unidad de medida. <kbd>F4</kbd> ofrece todas las unidades con su nombre. Si el código no existe, el campo lo marca con [`VALUE_NOT_FOUND`](/referencia/mensajes#value-not-found).

## Ficha {#ficha}

La ficha muestra el código y el nombre en solo lectura. <kbd>F3</kbd> vuelve a la pantalla inicial.
