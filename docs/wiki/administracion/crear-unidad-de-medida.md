# Crear unidad de medida (ZW81)

La transacción `ZW81` da de alta una unidad de medida. Exige el permiso [`catalog.manage`](/referencia/permisos#catalog-manage) y está en el menú en **Logística ▸ Catálogo**. La lista de todas las unidades está en [Gestionar unidades de medida](./unidades-de-medida).

## Crear una unidad de medida {#crear}

1. Complete la **Unidad** y el **Nombre**.
2. Grabe con <kbd>Ctrl</kbd>+<kbd>S</kbd>. Si el código ya existe, el campo lo marca con [`VALUE_ALREADY_EXISTS`](/referencia/mensajes#value-already-exists). Si no, el sistema informa **Unidad de medida creada.** y deja la ficha vacía para la siguiente.
